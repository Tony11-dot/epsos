# إبسوس — Epsos

موقعٌ تعريفيّ من صفحة واحدة مع لوحة تحكّم (CMS) لمعهد إبسوس للبسيخومتري.
عربيّ بالكامل، اتجاه RTL، وكل تفصيلة قابلة للتعديل من `/admin`.

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind v4 · OKLCH · Lenis.

---

## التشغيل محليًّا

```bash
pnpm install
pnpm dev
```

- الموقع: <http://localhost:3000>
- لوحة التحكم: <http://localhost:3000/admin>
- كلمة المرور الافتراضية للتجربة: **`epsos2024`** (تُضبط في `.env.local`).

> عند أول تشغيل يُعرض المحتوى الافتراضي (seed). أي حفظ من اللوحة يُنشئ الملف
> `content/data.json` (غير متعقّب في git) ويُطبّق فورًا على الموقع.

## البناء

```bash
pnpm build && pnpm start
```

## المتغيّرات البيئيّة

انظر `.env.example`. أهمّها:

| المتغيّر | الوصف |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم |
| `SESSION_SECRET` | مفتاح توقيع جلسة الأدمن (سلسلة عشوائية طويلة) |
| `STORE_DRIVER` | `local` (ملفات JSON، افتراضي) أو `redis` (Upstash للإنتاج) |
| `BLOB_DRIVER` | `local` (مجلّد `public/uploads`) أو `blob` (Vercel Blob للإنتاج) |

### التبديل إلى الإنتاج

- **المحتوى:** اضبط `STORE_DRIVER=redis` + `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN`.
- **الصور:** اضبط `BLOB_DRIVER=blob` + `BLOB_READ_WRITE_TOKEN`.

الطبقتان قابلتان للتبديل خلف واجهة واحدة — لا تغيير في بقيّة الكود.

### التسجيلات → Google Sheets

نموذج التسجيل (قسم «التسجيل» + الزر العائم) يرسل البيانات إلى جدول Google Sheets:

1. افتح ملف [`docs/apps-script.gs`](docs/apps-script.gs) واتبع خطوات الإعداد (≈ دقيقتان):
   ألصق الكود في Apps Script داخل الجدول، انشره كـ Web App، وانسخ الرابط.
2. ضع الرابط في `SHEETS_WEBHOOK_URL` ثم أعد التشغيل.

تُحفظ نسخة احتياطية محليًّا في `content/registrations.json` دائمًا، لذا لا تُفقد أي
بيانات حتى قبل ربط الجدول. الحقول: الاسم، العائلة، الهاتف، المدينة، البريد، الدورة
(الدورات تُشتق تلقائيًّا من الدورات التي يديرها المشرف؛ قائمة المدن قابلة للتعديل من اللوحة).

## البنية

```
src/
  app/
    layout.tsx            جذر الصفحة: RTL، الخطوط، حقن ألوان العلامة وقت الطلب
    page.tsx              الصفحة الواحدة (تجميع الأقسام)
    globals.css           رموز التصميم (OKLCH)، RTL، الحركة، بدائل reduced-motion
    admin/
      login/page.tsx      تسجيل الدخول
      (dash)/             لوحة التحكم (محميّة بحارس على الخادم)
      actions.ts          إجراءات الخادم: دخول/خروج/حفظ/رفع صور
    middleware.ts         إعادة توجيه UX لمسارات /admin (التحقق الفعلي على الخادم)
  lib/
    types.ts              نموذج المحتوى (يقود الموقع واللوحة معًا)
    seed.ts               المحتوى الافتراضي
    color.ts              اشتقاق تدرّج الأحمر كاملًا من لونٍ واحد (OKLCH)
    store.ts              طبقة المحتوى القابلة للتبديل (JSON ⇄ Redis)
    upload.ts             طبقة الصور القابلة للتبديل (محلّي ⇄ Vercel Blob)
    auth.ts               توقيع الجلسة (HMAC) والتحقق منها
  components/
    site/                 أقسام الموقع العامّة
    admin/                محرّرات اللوحة والحقول ورافع الصور ومنتقي الألوان
    (مشتركة)              الأيقونات، البدائل المُصمّمة، الحركة، النوافذ
```

### أفكار التصميم

- **المفهوم:** «قلم المعلّم الأحمر» — حبرٌ أحمر على ورقٍ قريب من الأبيض.
- **اللون:** كامل تدرّج الأحمر يُشتقّ من لونٍ واحد قابل للتعديل من اللوحة (OKLCH).
- **الخطوط:** Reem Kufi للعناوين، Readex Pro للنصوص، Rubik للأرقام.
- **الحركة:** تمرير سلس (Lenis)، ظهور بالتمرير، تصاعد الأرقام — جميعها تتوقّف
  تلقائيًّا مع `prefers-reduced-motion`.
- **إمكانية الوصول:** تباين يفي بـ WCAG AA، بؤرة واضحة، نوافذ محاصِرة للتركيز.

### ملاحظة على المحتوى

الأسماء والعلامات في «لوحة الأوائل» والمحاضرين هي عيّناتٌ مبدئيّة للاستبدال من
اللوحة — لم تُختلق بيانات حقيقيّة.
